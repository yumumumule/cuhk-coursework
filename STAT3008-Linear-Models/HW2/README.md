# Homework 2 — Multiple Regression and Diagnostics

**STAT3008A | The Chinese University of Hong Kong**

This assignment covers multiple linear regression, hypothesis testing, model comparison, prediction, and regression diagnostics using R.

## Problem 2 — Examination Score Prediction

Analyze the relationship between students' final examination scores and their scores on two preliminary examinations.

**Tasks:**
- Fit two simple linear regression models and one multiple regression model.
- Test the significance of the intercept in each model.
- Compare the predictive performance of the preliminary examination scores.
- Select a model and construct a prediction interval for a student's final score.

**Code:** `Problem2.R`

## Problem 4 — Joint Hypothesis Testing

Use supervisor performance data to examine joint restrictions on regression coefficients.

**Tasks:**
- Fit regression models with two and three predictors.
- Test the joint hypothesis that two specified regression coefficients both equal 0.5.
- Evaluate the hypothesis under different model specifications.

**Code:** `Problem4.R`

## Problem 7 — Regression Diagnostics

Analyze computer repair time as a function of the number of units serviced.

**Tasks:**
- Fit a simple linear regression model.
- Examine the standard regression assumptions.
- Use regression diagnostics to identify potential model inadequacies.

**Code:** `Problem7.R`
